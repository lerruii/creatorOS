Configurar CreatorOS

Solo necesitas hacer esto una vez. Conecta tu base de datos de Firebase para habilitar usuarios y sincronización en tiempo real.

Paso 1 — Firebase Realtime Database
URL de tu base de datos

Ve a console.firebase.google.com → tu proyecto → Realtime Database. Copia la URL (termina en .firebaseio.com).

Paso 2 — Reglas de Firebase
Abre las reglas y pégalas

En Firebase Console → Realtime Database → Reglas, reemplaza todo con:

{ "rules": { ".read": true, ".write": true } }
