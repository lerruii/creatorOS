Conectar Firebase
Sigue estos pasos una sola vez para que tu equipo comparta datos en tiempo real.
1
Ve a console.firebase.google.com e inicia sesión con tu cuenta de Google.
2
Crea un proyecto nuevo → ponle nombre (ej. creatorOS) → desactiva Analytics si quieres → Crear proyecto.
3
En el panel del proyecto, haz clic en el ícono </> (Web) para agregar una app web. Registra la app con cualquier nombre.
4
Ve a Build → Realtime Database → Create database. Elige una región, y en Security rules selecciona Start in test mode.
5
En la configuración de tu app web, copia el objeto firebaseConfig y pégalo abajo.

Si eliges «solo local», los datos no se comparten. Puedes conectar después en Ajustes.
